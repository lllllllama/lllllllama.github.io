运行 README 里的测试

在 2026 年 9 月 6 日的安装验收中，Agent 读取了 micrograd 原始 README，选择 python -m pytest 作为入口。首次独立试用通过了全部 2 项测试。

  • 验收设置与完整证据
  • 带日志回链的 README

查明环境失败并重跑

随后的一次重跑未将虚拟环境加入 PATH，子进程选中了没有 pytest 的 Python。失败保留在状态文件里。修正运行环境后，原来的两项测试全部通过，独立的 pytest 复核也得到了相同结果。

  • 失败状态
